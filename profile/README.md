# RuleBeat

Azure operations and governance platform. Reader-only, self-hosted, Apache-2.0.

RuleBeat turns Azure Resource Graph checks into a shared, scheduled governance
workflow for Azure platform teams — history, exceptions, dashboards, and
notifications. We never hold write credentials and never block deployments.

- **Website:** [rulebeat.com](https://rulebeat.com)
