# RuleBeat

RuleBeat runs the governance checks your team writes for Azure on a schedule,
tracks every finding over time, and never holds write access. It is open
source (Apache-2.0) and free, and it runs entirely inside your own Azure
subscription: one container, no external database, no telemetry. Nothing
about your tenant leaves your deployment.
